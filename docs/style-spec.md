# 像素艺术风格 —— 风格规格与提示词库

> 本文件只描述**风格(style)**,不绑定任何具体文案、字样、图形或画面内容。
> 所有需要你替换的部分一律写成占位符,例如 `【主标题】`、`【主色】`。

---

## 一、一句话定义

**8-bit / 终端美学**:一切形体由方块像素网格拼合而成,纯色扁平填充,右下带纯色硬投影,零抗锯齿、零渐变、零圆角。

判断是否合格只有一条:**放大后,每条边缘都必须是阶梯状的方块,不能出现任何一条平滑曲线或半透明羽化边。**

---

## 二、风格三要素(拆开看,一共就这三层)

| 层级     | 是什么                    | 为什么是它                   |
| ------ | ---------------------- | ----------------------- |
| **骨架** | 方块像素网格 + 阶梯状斜角         | 一切边缘呈方块状,是 8-bit 的定义性特征 |
| **填充** | 纯色扁平,无渐变/无渐变阴影/无滤镜/无纹理 | 复古硬件无渐变渲染能力             |
| **光影** | 右下方向、纯色、硬边、偏移 1 格      | 用"假光影"暗示立体,代替真实明暗       |

任何时候拿不准,把要素往这三个里对,对上了就是该风格。

---

## 三、风格不变式清单(换内容时逐条核对)

**网格类**

- [ ] 所有形体由方形像素块拼合,不是矢量曲线
- [ ] 斜角、圆弧、箭头一律走阶梯状过渡
- [ ] 圆角 = 0
- [ ] 所有坐标为整数,禁止半像素
- [ ] 关闭抗锯齿(`shape-rendering="crispEdges"` 或等价手段)

**填充类**

- [ ] 纯色填充,无渐变、无 mesh、无噪点、无纹理、无滤镜
- [ ] 投影/阴影是纯色硬边,不透明度 100%,无模糊半径、无羽化

**光影类**

- [ ] 投影方向统一(惯例:右下)
- [ ] 投影偏移量 = 1 个像素格(大标题可用 2 格)
- [ ] 投影层与主体层共用同一份几何数据,只做偏移,不做二次绘制

**文字类**

- [ ] 全部文字使用点阵/位图字体,笔画宽度恒定
- [ ] 字距紧凑,通常 = 1 个笔画宽
- [ ] 层级靠**字号 + 笔画粗细**区分,不用字体家族区分
- [ ] 允许大小写混合(注意:部分像素字体无小写字形,需换字体)

**用色类**

- [ ] 全图色板 ≤ 4 色
- [ ] 背景纯色
- [ ] 强调色唯一,只允许出现一次(通常是那条装饰线)
- [ ] 正文色与主色分工明确,不混用

**构图类**

- [ ] 元素左对齐或居中,二选一,全图统一
- [ ] 留白充足,元素间距 ≥ 2 倍笔画宽
- [ ] 装饰线在文本层级之间作为分隔,末端带方块收尾

## 四、路线 B:直接喂给 SVG 生成模型的提示词

适合:只要"这股味道",不在乎文字精确。
用法:把 `【】` 里的内容换成你的,直接整段复制。

```
像素艺术（8-bit / 复古终端）风格的【作品类型】。

骨架：所有形体均由规整的方块像素拼合而成，边缘绝对锐利，
      斜角与转折处呈阶梯状过渡，无任何圆角、平滑曲线与抗锯齿。
      全部坐标落在整数像素网格上。

主形：【主标题】使用超粗点阵像素字体，字形轮廓由方块像素拼合；
      填充【主色】；右下叠加【投影色】的纯色硬投影，
      偏移量约一个像素格，投影边缘清晰，无模糊、无羽化、无渐变。

次级文字：【副标题】与【说明文字】均为点阵像素字体，笔画宽度固定，
      字距紧凑；副标题全大写，说明文字允许大小写混合，颜色【字色】。

装饰：一条纯色水平分隔线（厚度约等于一个笔画宽），
      末端带一个同色实心方块收尾。

画布：纯色底【底色】。整体扁平色块，无渐变、无光晕、无纹理、无噪点。
      全图色板不超过 4 色，其中强调色【强调色】仅出现一次。
      画面比例【宽高比】，元素【左对齐/居中】，留白充足。
```

### 补丁词(追加到提示词末尾,越靠后权重越高)

```
所有像素块必须对齐到整数像素网格，禁止半像素坐标；
关闭抗锯齿；禁止矢量平滑曲线；所有边缘呈阶梯状。
```

### 若模型仍输出平滑字形:改用「字形网格描述法」

模型对网格数据的还原率远高于自然语言描述。把字形显式写成网格喂给它:

```
字母 R，7×9 像素网格（# = 实心，. = 空白）：
#########
#########
#########
#########
#########
##########
#########
#########
.######..
```

## 五、路线 A:代码生成 SVG(推荐,锐利可控)

### A1. 风格参数(实测值,直接复用)

```
像素网格    大标题纵向笔画 15-16px、横向 30px（=2 格）
            小字笔画恒定 6px
投影        右下偏移 12px，纯色硬边，无羽化无模糊
装饰线      厚度 6-8px，右端叠一个 24×22px 同色方块
圆角        0
抗锯齿      关闭，所有坐标取整数
```

### A2. 色板(参考图原味,仅作起点,可整组替换)

```
底色      #EEF1F6   浅冷灰
主色      #02ADFB   高饱和蓝，仅用于主标题
字色      #1F1F1F   近黑
强调色    #FF6104   唯一暖色，仅用于分隔线
投影色    #2B3444   深蓝黑
```

### A3. 生成的提示词(给 AI 的,同样占位符化)

```
用 Python 生成像素艺术风格 Logo，输出 SVG 后转 PNG。

要求：
1. 用位图字体（Press Start 2P / Silkscreen / Pixelify Sans）渲染文本，
   把渲染结果的 alpha 掩膜转成水平合并的 <rect> 序列，
   而非直接用 <text>，确保每个像素块边界锐利无抗锯齿。
2. SVG 根元素加 shape-rendering="crispEdges"，所有坐标取整数。
3. 主体渲染两遍：先画投影层（右下偏移 12px，色【投影色】），
   再画主体层（色【主色】），实现硬投影。
4. 色板限定 4 色：底【底色】/ 主【主色】/ 字【字色】/ 强调【强调色】。
5. 装饰线加一条【强调色】横线，右端叠一个 24×22px 同色方块。
6. 圆角全部为 0，无渐变、无滤镜、无羽化阴影。
7. 转 PNG 用 Chrome headless：
   chrome --headless=new --screenshot=out.png --window-size=1080,600
   --force-device-scale-factor=2 file:///path/to/svg
   （headless 渲染 SVG 比 rsvg-convert 更能保留 font 效果）
```

### A4. 关键实现要点(踩过的坑)

- **投影层必须与主体层用同一张掩膜**,只是偏移不同。分别渲染两次会导致字形不一致。
- **不要用 `<text>` + `font-family`**:浏览器对 TTF 的 hinting 会破坏点阵感,且不同环境渲染结果不一致。
  转 `<rect>` 后 SVG 完全自包含、可移植。
- **Chrome headless 的 `--window-size` 要写死**并加 `--force-device-scale-factor=2`,
  否则按内容自适应高度,截出来会带白边。
- **Silkscreen 无小写**,说明文字若要大小写混合需换 Pixelify Sans。

## 六、配色替换速查

色板可整组替换,风格结构不变。换色时保持"底色冷/暖中性 + 主色高饱和 + 强调色唯一"的分工。

| 想要的感觉      | 主色      | 底色      | 强调色     | 投影色     |

| 冷调科技(参考原味) | #02ADFB | #EEF1F6 | #FF6104 | #2B3444 |
| 暗夜赛博       | #00E5A0 | #0D1117 | #FF3D81 | #05070C |
| 复古街机       | #FFD200 | #1B1F27 | #FF5F1F | #000000 |
| 柔和糖果       | #FF7EB6 | #FFF5F7 | #4ECDC4 | #8A5A72 |
| 极简专业       | #2563EB | #F8FAFC | #F97316 | #1E293B |

## 七、风格强度调节

同一套风格可按目标粗细微调,不改风格本体:

| 参数    | 收紧             | 放松         |
| ----- | -------------- | ---------- |
| 像素格大小 | 格更大、更粗犷(复古机感强) | 格更小、更细腻    |
| 投影偏移  | 0(纯扁平)         | 2 格(浮雕感强)  |
| 强调色用法 | 只用于分隔线         | 兼用于点缀小方块   |
| 字重层级差 | 三级字号差距小        | 差距拉大,主次更分明 |

## 八、配套实现(本包结构)

```
pixel-logo-toolkit/
├─ src/pixellogo/            生成器实现
│  ├─ text.py                文本 → 二值掩膜 → 水平游程 → 整数矩形
│  ├─ layout.py              行栈排版（标题投影、分隔线、徽标）
│  ├─ presets.py             五套配色预设
│  ├─ modes.py               三种画布规格
│  ├─ fonts.py               字体注册与字形覆盖检测
│  └─ render/                SVG 与 PNG 双后端
├─ src/pixellogo/assets/
│  ├─ fonts/                 PressStart2P / Silkscreen / PixelifySans / ArkPixel
│  └─ licenses/              四份 SIL OFL 1.1 许可原文
├─ examples/                 可直接运行的 JSONC 配置
└─ docs/                     本文件与设计文档
```

### 常用命令

```bash
# 三模式出图
pixellogo -t "【主标题】" -s "【副标题】" -d "【说明文字】" -m xhs
pixellogo -t "【主标题】" -m 4:3 -f png -o out/
pixellogo -t "【主标题】" -m og  -f svg -o out/

# 换配色预设
pixellogo -t "【主标题】" -p cyber

# 用配置文件
pixellogo -c examples/og.jsonc --dry-run
```

> 风格参数全部落在整数像素网格上：文字先转二值掩膜，再按行合并成矩形，
> 因此 PNG 与 SVG 出自同一份几何，放大后不会出现平滑边缘。
